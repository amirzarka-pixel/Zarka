# אוסטריה 2027: אפליקציית הטיול

אפליקציה שמותקנת בטלפון (PWA) ובה מפה, מקומות, תוכנית ימים, הצבעות ויומן תמונות משותף.
היא מתארחת ב-GitHub Pages והנתונים נשמרים ב-Firebase. אין צורך בחשבון: כל משתתף רק כותב את השם שלו.

## הקמה (כ-15 דקות)

### 1. Firebase
1. נכנסים ל-https://console.firebase.google.com, לוחצים **Add project** וקוראים לו למשל `austria-2027`. אפשר לכבות את Analytics.
2. **Build → Authentication → Get started → Sign-in method**: מפעילים **Anonymous**.
3. **Build → Firestore Database → Create database**: בוחרים מיקום `eur3` (אירופה) ומצב **production**.
4. בלשונית **Rules** של Firestore מדביקים את כל התוכן של הקובץ `firestore.rules` ולוחצים **Publish**.
5. **Project settings** (גלגל השיניים) → **Your apps** → לוחצים על סמל ה-Web `</>`, נותנים שם ולוחצים Register.
   מעתיקים את האובייקט `firebaseConfig`.
6. בקובץ `firebase-config.js` מחליפים את `null` באובייקט שהעתקתם (יש דוגמה בתוך הקובץ).

התוכנית החינמית (Spark) מספיקה: התמונות נשמרות מכווצות בתוך Firestore, ולכן אין צורך ב-Storage ובתשלום.

### 2. GitHub Pages
1. יוצרים מאגר חדש ב-GitHub (או תיקייה במאגר קיים) ומעלים אליו את כל הקבצים.
2. **Settings → Pages → Source: Deploy from a branch**, בוחרים `main` ואת התיקייה המתאימה ושומרים.
3. אחרי דקה-שתיים מקבלים כתובת כמו `https://<user>.github.io/<repo>/`.
4. ב-Firebase: **Authentication → Settings → Authorized domains** → מוסיפים `<user>.github.io`.

### 3. שיתוף
שולחים את הכתובת לקבוצת הווטסאפ. כל אחד פותח אותה, כותב את השם שלו ומוסיף למסך הבית:
- אנדרואיד (Chrome): תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה".
- אייפון (Safari): כפתור השיתוף ← "הוסף למסך הבית".

## קבצים
| קובץ | מה יש בו |
|---|---|
| `index.html` | המבנה והעיצוב |
| `app.js` | כל הלוגיקה: מפה, הצבעות, ימים, תמונות |
| `data.js` | 45 המקומות מהמפה של אדווה, האזורים וההצעה לתוכנית. כאן מוסיפים או מעדכנים מקומות |
| `firebase-config.js` | פרטי החיבור ל-Firebase |
| `firestore.rules` | כללי האבטחה של מסד הנתונים |
| `sw.js` | שמירה לשימוש בלי קליטה (גם אריחי מפה שכבר נצפו) |

## הערות
- כל אחד יכול למחוק רק תמונות שהוא העלה.
- התמונות מכווצות לפני ההעלאה: עד 1600 פיקסלים, ועד 10 תמונות בכל פעם.
- זמני הנסיעה הם הערכה לפי מרחק. הזמן המדויק מופיע בכפתור הניווט.
- אחרי עדכון קבצים כדאי לשנות את `V` בקובץ `sw.js` (למשל ל-`trip-v2`), כדי שהטלפונים יקבלו את הגרסה החדשה.
